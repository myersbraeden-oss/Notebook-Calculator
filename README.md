Intro:

This notebook calculator was a play on ideas by combining 
features of a physical notebook and adding computing abilities 
through code.


How to Use:

This is currently in the proof of concept phase. Right-click on 
any line to open a text field and write notes or expressions. 
When writing expressions, the notebook can evaluate them for you
by pressing '='. It only handles these operators for now (+, -, *, /).
A common trait of buit-in calculators is they show a result after
inputting 2 numbers. Where this calculator is different is it can
hanlde any amount of numbers and parentheses as well.
